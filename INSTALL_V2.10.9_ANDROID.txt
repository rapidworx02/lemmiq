============================================================

2. EXTRACT V2.10.9
============================================================

Extract:
LEMMIQ_V2.10.9_ANDROID_INTEGRATION.zip

Inside it you will see:
LEMMIQ_V2.10.9_ANDROID_INTEGRATION\android\app\

Copy/merge the `android` folder into:

C:\Users\pc\LEMMIQ\

IMPORTANT:

============================================================

findstr /n /i "versionCode=59" android\app\build.gradle.kts

5. COMMIT
============================================================

cd /d C:\Users\pc\LEMMIQ

git add android\app
git status

git commit -m "LEMMIQ V2.10.9 integrate Q Economy into Android"
git push origin main

============================================================
6. BUILD DEBUG APK
============================================================

cd /d C:\Users\pc\LEMMIQ\android

gradlew clean
gradlew assembleDebug

Expected APK:

C:\Users\pc\LEMMIQ\android\app\build\outputs\apk\debug\app-debug.apk

============================================================
7. INSTALL ON PHONE
============================================================

adb install -r app\build\outputs\apk\debug\app-debug.apk

If you receive a SIGNATURE MISMATCH only:

adb uninstall com.lemmiq.app
adb install app\build\outputs\apk\debug\app-debug.apk

WARNING:
adb uninstall com.lemmiq.app removes the locally stored app/session data.
Use uninstall only when a signing-key mismatch requires it.

============================================================

============================================================

Login normally.

Confirm bottom navigation is exactly:

Chats · Updates · Q Economy · Q Predict · Calls · More
