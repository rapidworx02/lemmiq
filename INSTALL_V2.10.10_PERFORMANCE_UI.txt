============================================================
8) OPTIONAL PWA NOTIFICATIONS
============================================================

If you only want UI/performance now, skip this section.
The rest of V2.10.10 works without PWA push variables.

Because Android FCM already uses your Firebase project, add a Firebase Web App in the same project.

Firebase Console:
Project settings > General > Your apps > Add app > Web

Copy the Firebase web config JSON.

Then:
Project settings > Cloud Messaging > Web Push certificates
Generate/copy the public VAPID key.

In Render > lemmiq-api > Environment add:

FIREBASE_WEB_CONFIG_JSON

Value example (USE YOUR REAL FIREBASE VALUES):
{"apiKey":"...","authDomain":"...","projectId":"...","storageBucket":"...","messagingSenderId":"...","appId":"..."}

FIREBASE_WEB_VAPID_KEY

Value:
your public Web Push certificate/VAPID key

Keep your existing Firebase Admin credential:
FIREBASE_SERVICE_ACCOUNT_JSON
or FIREBASE_SERVICE_ACCOUNT_B64

Redeploy Render.

Then sign into LEMMIQ PWA:
More > Browser notifications > tap to enable

Allow notifications in Chrome.

Test by sending a message from another LEMMIQ account while the PWA is in the background.

============================================================
9) PERFORMANCE CHECK
============================================================

In Chrome DevTools > Network, API responses now include:

Server-Timing
X-LEMMIQ-Server-Ms

Render logs will also show:
Slow request ... ms METHOD /path

for backend requests taking 750 ms or longer.

This helps identify whether remaining slowness is:
- Render/server
- PostgreSQL
- AI/provider calls
- browser rendering
