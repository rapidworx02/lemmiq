LEMMIQ V2.8.1 PATCH
Q ECONOMY BOTTOM TAB + OPTIONAL REFERRAL CODE AT SIGNUP
======================================================

WHAT CHANGED
------------
1. Q Economy is now a MAIN bottom/home navigation tab.
2. Q Economy is removed from the More menu to avoid duplication.
3. Main navigation is now:
   Chats | Updates | Q | Q Economy | Calls | More
4. Create Account now includes:
   Referral code (optional)
5. Referral code is NOT mandatory.
6. If a valid referral code is entered during signup:
   - the new account is created normally;
   - the standard signup Q bonus is applied;
   - the referred-user Q reward is applied;
   - the referrer Q reward is applied;
   - the referral is recorded immediately.
7. If referral is left blank:
   - signup works exactly as normal;
   - the user can still use the existing Refer & Earn screen later.
8. Invalid referral code entered during signup returns a clear error and the
   account is not created.
9. Android version:
   versionName 2.8.1
   versionCode 46
10. Web/PWA cache is bumped so mobile browsers refresh the navigation.

REFERRAL BEHAVIOUR
------------------
Referral input format example:
Q123-ABCDEF

It is optional.

Blank:
signup continues normally.

Valid:
referrer + referred-user rewards are issued according to Q Admin settings.

Invalid:
signup is stopped before account creation so the user can correct/remove the
code.

No second-level/downline reward is created. Existing one-level Refer & Earn
rules remain unchanged.
