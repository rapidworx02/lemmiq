LEMMIQ Android private-beta download folder.

To make https://YOUR-RENDER-SERVICE/download/android work without an external URL:
1. Build a signed APK (preferred) or test APK in Android Studio.
2. Rename it to LEMMIQ.apk.
3. Place it in this folder.
4. Commit/push and let Render redeploy.

The APK itself is intentionally not included in the source ZIP because it must be compiled/signed from your Android build.
