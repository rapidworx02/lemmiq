LEMMIQ V2.8 - Q ECONOMY BETA
================================

IMPORTANT
---------
V2.8 adds a centralised Q utility economy, Q Wallet, Basic Q daily claim,
Refer & Earn, paid Q subscription lots, manual USDT TRC20/BEP20 payment
submission and admin activation, Q Marketplace with escrow, Admin Profit
Wallet, treasury controls, and browser-first Q Admin.

Cash-out is DISABLED in V2.8. Do not market Q as guaranteed cash income or
a guaranteed investment return. Obtain appropriate Australian legal/financial
and AML/CTF advice before enabling redemption/cash-out.

CURRENT Q MODEL
---------------
Maximum supply:          1,000,000,000 Q
Initial unlocked:           10,000,000 Q
Locked reserve:            990,000,000 Q
Starting reference:              US$0.05/Q

Opening system wallets:
USAGE_MINING              6,000,000 Q
MARKET_REWARDS            2,000,000 Q
REFERRALS                 1,000,000 Q
PROMOTIONS                1,000,000 Q
PROFIT                             0 Q
ESCROW                             0 Q
LOCKED_RESERVE           990,000,000 Q

Default Basic Q/day: 2 Q
Default signup bonus: 100 Q
Default referral reward: 25 Q to referrer + 25 Q to referred user
Default marketplace fee: 5% to Admin PROFIT wallet
All of these values can be changed from Q Admin except maximum supply.

PACKAGES
--------
Starter     US$10      0.25% daily package value
Plus        US$50      0.50% daily package value
Pro         US$100     0.75% daily package value
Premium     US$500     1.00% daily package value
Elite       US$1,000   1.25% daily package value

Each paid package:
- is a separate subscription lot;
- starts only after Admin approves the submitted USDT transaction;
- remains valid for up to 365 days;
- stops package accrual when its 200% package-value ceiling is reached;
- converts the daily USD-equivalent accrual into Q using the current Q
  reference price at the time accrual is processed;
- keeps a separate USD-equivalent accrued/cap ledger for future liability control.

STEP 5 - USER USDT PAYMENT FLOW
-------------------------------
User:
1. Opens More -> Q Economy -> Packages.
2. Selects package.
3. Chooses USDT TRC20 or USDT BEP20.
4. LEMMIQ creates a unique payment Order ID.
5. User sends the exact USDT amount to the displayed public address.
6. User submits the blockchain transaction hash.
7. Payment status becomes PENDING.

Admin:
1. Opens Q Admin -> Pending USDT payments.
2. Opens transaction in TronScan/BscScan.
3. Manually verifies:
   - token is USDT;
   - correct network;
   - destination address;
   - amount;
   - transaction hash;
   - successful/on-chain transaction.
4. Clicks Approve or Reject.

Approve automatically:
- marks payment APPROVED;
- creates a 365-day package lot;
- attaches the correct daily package rate;
- attaches the 200% package ceiling;
- starts package accrual from the following day.

Admin should NEVER manually edit a user's Q balance for package activation.

IMPORTANT:

and regular backups before putting financial-value records into production.

SECURITY / OPERATING RULES
--------------------------
- Only public USDT receiving addresses go into LEMMIQ.
- Transaction hashes are not proof by themselves: Admin verifies on-chain.
- Never approve a payment merely because a user submitted a screenshot.
- Package activation is idempotent: one payment order can create one package lot.
- Duplicate transaction hashes are rejected.
- User Q transfers and all treasury movements create immutable ledger records.
- Treasury balances must not be edited directly.
- Cash-out remains disabled in V2.8.
- Do not rely on new subscriber funds as the sole source for future withdrawals.

ADMIN TEAM / ROLES
------------------
Master Admin can add/update other LEMMIQ users as:
- FINANCE_ADMIN
- MARKETPLACE_ADMIN
- SUPPORT_ADMIN
- RISK_ADMIN
- READ_ONLY
- MASTER_ADMIN

Finance Admin can approve/reject manual USDT payment submissions.
Marketplace/Risk Admin can resolve Q Market disputes.
Treasury/config/payment-wallet changes remain Master Admin only.
The signed-in Master Admin cannot accidentally demote/disable itself.

CUSTOM QR
---------
A QR is generated automatically from every configured public wallet address.
Q Admin also supports uploading a custom QR image for a receiving wallet.
The displayed wallet address remains visible so users can compare the text
address with the QR before paying.

EDITABLE Q MARKET LISTINGS
--------------------------
Sellers can edit title, description, Q price, inventory and active/paused
status from the web and Android V2.8 Q Market screens.
