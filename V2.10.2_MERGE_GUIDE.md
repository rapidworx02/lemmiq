# LEMMIQ V2.10.2 — Native Android merge guide

This patch targets the problems still visible in the V2.10.1 Android build:

1. Android still shows only 5 bottom tabs.
2. Q sheet still shows `Profile, Trust, Business & Settings`.
3. Chat image attachments still do not behave like photos.
4. Photo bubbles still have too much coloured padding.
5. Tapping a photo should open a full-screen zoomable viewer.
6. The earlier call Decline reliability fix should remain wired in.

## Files in this patch

Copy these three files to:

`android/app/src/main/java/com/lemmiq/app/`

- `LemmiqUiV2102.kt`
- `LemmiqChatMediaV2102.kt`
- `CallDeclineV2102.kt`

These are support components. The real `LemmiqApp.kt` must call them. Merely copying the files will not change the UI.

## F. Chat photo rendering

Find the message attachment branch in `LemmiqApp.kt`.

Your build logs previously showed attachment rendering around `LemmiqApp.kt`, so this is the correct native UI file to change.

For an attachment, first determine whether it is an image:

```kotlin
val isPhoto = isLemmiqImageAttachmentV2102(
    kind = message.attachment?.kind,
    mimeType = message.attachment?.mime_type,
    fileName = message.attachment?.name
)
```

Adapt property names if your DTO uses `mime`, `content_type`, etc.

For a DIRECT CHAT photo:

```kotlin
if (isPhoto) {
    LemmiqChatPhotoV2102(
        imageLoader = {
            LemmiqMediaLoaderV2102.directMessage(
                serverBaseUrl = SERVER_URL,
                authToken = authToken,
                messageId = message.id.toLong()
            )
        },
        mine = message.sender_id == myUserId,
        timestamp = formattedTime,
        caption = message.text.takeIf { it.isNotBlank() },
        onAskQVision = {
            // call the existing Ask Q Vision action for this message
        }
    )
} else {
    // keep your existing file/voice/document attachment UI
}
```

For a GROUP CHAT image use:

```kotlin
LemmiqMediaLoaderV2102.groupMessage(
    serverBaseUrl = SERVER_URL,
    authToken = authToken,
    messageId = message.id.toLong()
)
```

### What this changes

- The photo itself fills almost all of the bubble.
- Coloured padding around the image is only 4dp.
- Tap opens full screen.
- Full screen supports pinch zoom, pan and double-tap zoom.
- Tap once in full screen hides/shows controls.
- Android Back closes the full-screen Dialog.
- Ask Q Vision remains directly under the image.

## G. Call decline

`CallDeclineV2102.kt` is included so V2.10.2 does not lose the earlier terminal-state protection.

Your existing Decline button must call `CallDeclineV2102.decline(...)`.

Also, before processing answer/connect callbacks, guard them with:

```kotlin
if (CallDeclineV2102.isTerminal(callId)) return
```

That stops a declined call from racing back into CONNECTING/CONNECTED.
