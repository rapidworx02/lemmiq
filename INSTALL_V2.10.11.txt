============================================================
6) OPTIONAL: ENABLE PWA PHONE NOTIFICATIONS
============================================================

If you do not want browser notifications yet, skip this section.
Everything else in V2.10.11 works without these variables.

In the SAME Firebase project used by the Android app:

Firebase Console > Project settings > General > Your apps > Add app > Web
Copy the Web config object as JSON.

Firebase Console > Project settings > Cloud Messaging > Web Push certificates
Generate/copy the PUBLIC VAPID key.

Render > lemmiq-api > Environment:

FIREBASE_WEB_CONFIG_JSON
Example structure (USE YOUR REAL VALUES):
{"apiKey":"...","authDomain":"...","projectId":"...","storageBucket":"...","messagingSenderId":"...","appId":"..."}

FIREBASE_WEB_VAPID_KEY
Value: your public Web Push / VAPID key

Keep your existing Firebase Admin variable:
FIREBASE_SERVICE_ACCOUNT_JSON
or
FIREBASE_SERVICE_ACCOUNT_B64

Redeploy Render.

On phone Chrome/PWA:
LEMMIQ > More > Appearance & notifications > Enable browser notifications
Then tap Allow.

============================================================
9) INSTALL ANDROID
============================================================

adb install -r app\build\outputs\apk\debug\app-debug.apk

Only if Android reports a signing/signature mismatch:

adb uninstall com.lemmiq.app
adb install app\build\outputs\apk\debug\app-debug.apk

WARNING: uninstall clears local app/session data. Use only for signature mismatch.
